# coder エージェント用ガイドライン

## いつ使うか

- 本リポジトリ（`shop_system`）で機能追加・修正・リファクタリング等の実装を行うとき

## 実装規約の正本

実装規約（re-export 禁止、Backend の3層構成、Front の実装規約など）は以下に一元化されている。実装前に必ず参照すること。

- `Backend/CLAUDE.md`（`Backend/`, `DB/` 向け: re-export 禁止、route/handler/データアクセスの3層構成）
- `Front/AGENTS.md`（`Front/` 向け: コンポーネント分割、Props の置き方、repository 層、TanStack Query など）

これらは Claude Code が自動的に読み込む場所に置いているため、coder エージェント経由でなく直接コードを編集する場合にも適用される。このスキルは coder エージェント固有の作業方針のみを補足する。

## coder エージェントとしての作業方針

- 実装前に、変更対象ディレクトリに対応する規約ファイル（上記）を確認し、遵守した上でコードを書く。
- 規約に反する既存コードを見つけても、依頼された変更の範囲を超えて無関係な箇所をリファクタリングしない。
- 規約に無い判断が必要な場合は、既存の類似実装のパターンに合わせる。
