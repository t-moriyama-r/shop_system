# 機能要件一覧

> バージョン: 3 | 更新日時: 2026/7/12 0:00:00

| id | functionName | description | relatedRequirement | priority |
| --- | --- | --- | --- | --- |
| FR-001 | ログイン画面表示機能 | システム管理者がログインするための認証情報（IDとしてのメールアドレスおよびパスワード）の入力フォームを提供する画面機能。 | BR-001 | 高 |
| FR-002 | ログイン認証・セッション管理機能 | 入力された認証情報を検証し、認証に成功した場合はセッションを開始してダッシュボード画面へ遷移させる。※要確認（一定時間無操作によるセッション自動切断機能、セッション保持期間、セキュリティ要件等の技術制約） | BR-001, BR-002 | 高 |
| FR-003 | ログインエラーハンドリング・画面制御機能 | 認証失敗時に適切なエラーメッセージを表示し、再入力を促す。※要確認（連続失敗時のアカウントロック機能やセキュリティ対策ポリシー等のドメイン知識） | BR-003 | 高 |
| FR-004 | ログアウト機能 | ダッシュボード等の管理画面共通ヘッダーに配置されたログアウトボタン押下により、セッションを安全に破棄し、ログイン画面へ強制遷移させる機能。 | BR-002 | 中 |
| FR-005 | パスワード変更画面 | アカウント追加時にランダム生成された初期パスワードがメール送付されるため、初回ログイン後に初期パスワードから新しいパスワードへの変更を強制する画面を作成する。 | BR-004 | 高 |
| FR-006 | SE管理者アカウント削除画面 | SE管理者アカウントを削除するための画面 | BR-005 | 高 |
| FR-007 | ダッシュボード画面表示機能 | ログイン成功後のトップ画面として、システムサマリー情報や顧客アカウントの発行状況（一覧表示）を一括で閲覧可能とするメイン画面機能。 | BR-009, BR-010 | 高 |
| FR-008 | システム稼働サマリー情報取得API | ダッシュボードにシステム状況（稼働状態やSE作業サマリー）を表示するため、サーバー側からデータを取得する機能。※要確認（表示対象となるシステムステータスの詳細定義は、ドメイン知識が未提供のため要確認） | BR-009 | 中 |
| FR-009 | 顧客アカウント発行状況監視・一覧表示機能 | 直近で実行された新規顧客アカウントの発行処理状況（成功、処理中、エラー等のステータス）をダッシュボード上にリスト表示する機能。エラー発生時には詳細やログ情報等へアクセスする経路（リンク等）を設ける（※要確認：エラーログの詳細レベルおよび画面遷移仕様の確認が必要）。 | BR-010 | 高 |
| FR-010 | 新規顧客アカウント発行画面表示機能 | 管理画面より顧客のアカウントを新規発行するための、情報入力フォーム（会社名、担当者名、メールアドレス等の項目）を表示する画面機能。※要確認（入力必須・推奨項目等の詳細） | BR-006, BR-007 | 高 |
| FR-011 | 顧客アカウント新規登録・バリデーション機能（C/U処理） | 入力された顧客アカウント情報を取得し、形式チェック、必須チェック、および既存データとの重複チェックを実行した上で、データベースへ新規登録（Create）する機能。 | BR-006, BR-007 | 高 |
| FR-012 | 顧客アカウント発行完了通知送信機能（バックグラウンド処理） | 顧客アカウントの登録成功をトリガーとし、登録された顧客のメールアドレス宛てにログイン用の初期IDや一時パスワード、利用案内などのメール通知を自動送信する機能。※要確認（通知手段がメールか他のチャネルか、および送信テンプレート形式、暗号化等の技術制約・ドメイン知識） | BR-008 | 中 |
