# 非機能要件一覧

> バージョン: 3 | 更新日時: 2026/7/2 0:15:05

| id | category | requirement | targetValue | priority |
| --- | --- | --- | --- | --- |
| NFR-001 | 性能 | 画面応答速度 | ダッシュボードおよび顧客アカウント発行画面の表示速度について、通常時：平均2秒以内、ピーク時：平均3秒以内（ネットワーク遅延を除くサーバー側処理時間）※要確認 | 中 |
| NFR-002 | 性能 | 同時アクセス数 | 最大同時アクティブユーザー数10名程度を想定。※要確認 | 低 |
| NFR-003 | 可用性 | システム稼働時間 | 平日9:00〜18:00における稼働率99.5%以上。夜間・休日の計画メンテナンスによるシステム停止は許容。※要確認 | 中 |
| NFR-004 | 可用性 | 目標復旧時間（RTO）/ 目標復旧時点（RPO） | 未定義（インフラ構成・ディザスタリカバリポリシーが未提供のため ※要確認） | 高 |
| NFR-005 | セキュリティ | 暗号化通信 | 管理画面Webサイトへのアクセス（HTTPS: TLS 1.2以上）およびデータベース接続等の内部通信はすべて暗号化すること。※要確認 | 高 |
| NFR-006 | セキュリティ | パスワードポリシー | パスワードは半角英数字・記号を混在させ8文字以上とすること。データベース保存時はソルト付加のうえハッシュ化すること。※要確認 | 高 |
| NFR-007 | セキュリティ | ログインエラー制限（アカウントロック） | 同一アカウントでの連続ログイン失敗5回でアカウントを一時ロックし、ロック解除はシステム管理者による手動対応のみ実行可能とすること。 | 高 |
| NFR-008 | セキュリティ | セッション管理 | ログイン成功から無操作状態が30分経過した場合、セッションを破棄しログイン画面へ強制遷移すること。 | 高 |
| NFR-009 | 運用 | 監査・操作ログの保持 | 管理者のログイン成否、顧客アカウント発行の実行履歴（実行日時、実行者、操作種別、対象情報）のログを安全に記録し、1ヶ月間保存すること（保持期間超過レコードは日次バッチで自動削除）。 | 高 |
| NFR-010 | 運用 | データバックアップ | 管理者および顧客アカウントデータ、操作ログについて日次で自動バックアップを処理し、過去30日間の履歴を世代管理すること。 | 中 |
| NFR-011 | 運用 | 監視と障害通知 | Webアプリケーション、データベースの死活監視を実施し、異常検知時に自動でアラートメールを運用管理者へ即時通知すること。 | 中 |
| NFR-012 | 拡張性 | リソース拡張性 | 将来的な顧客アカウント発行数の増加に対応できるよう、Web・データベースを容易にスケールアップ・アウト可能なクラウド構成、または疎結合なモジュール構造（プログラムの保守性）を考慮して設計すること。 | 中 |
