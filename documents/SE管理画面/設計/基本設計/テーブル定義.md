| sessions | expires_at | TIMESTAMP WITH TIME ZONE | NO | NO | セッション有効期限。無操作30分でタイムアウト ※要確認（セッションタイムアウト時間） |
| sessions | created_at | TIMESTAMP WITH TIME ZONE | NO | NO | セッション作成日時（ログイン日時） |

| shop_accounts | account_status | VARCHAR(50) | NO | NO | ショップアカウントステータス。例：'active'（有効）、'pending'（メール送信待ち）、'suspended'（停止） ※要確認（ステータス種別の詳細定義） |
| shop_accounts | issued_by_se_admin_user_id | UUID | NO | NO | ショップアカウントを発行したSE管理者ユーザーID。se_admin_usersテーブルへの外部キー |

| shop_accounts | deleted_at | TIMESTAMP WITH TIME ZONE | YES | NO | 論理削除日時 ※要確認（ショップアカウント削除機能の要否・方針） |
| shop_accounts | created_at | TIMESTAMP WITH TIME ZONE | NO | NO | レコード作成日時（アカウント発行日時） |
| shop_accounts | updated_at | TIMESTAMP WITH TIME ZONE | NO | NO | レコード最終更新日時 |

| audit_logs | target_type | VARCHAR(100) | YES | NO | 操作対象のリソース種別。例：'se_admin_user'、'shop_account'。対象なし操作の場合はNULL |

| audit_logs | detail | TEXT | YES | NO | 操作詳細情報（エラーメッセージ、変更内容の補足等）。機密情報（パスワード等）は記録しない |
| audit_logs | ip_address | VARCHAR(45) | YES | NO | 操作元IPアドレス（IPv4またはIPv6）。CLIによる操作の場合はNULLまたはサーバーIP ※要確認 |
| audit_logs | user_agent | TEXT | YES | NO | 操作元ブラウザのユーザーエージェント文字列。CLIによる操作の場合はNULL |
| audit_logs | created_at | TIMESTAMP WITH TIME ZONE | NO | NO | ログ記録日時。保持期間1年間。改ざん防止のためUPDATE・DELETE不可とする ※要確認（改ざん防止の実装方針） |

| email_notification_logs | notification_type | VARCHAR(100) | NO | NO | 通知種別。例：'SHOP_ACCOUNT_ISSUED'（アカウント発行完了通知） ※要確認（通知種別の追加要否） |
| email_notification_logs | send_status | VARCHAR(50) | NO | NO | 送信ステータス。例：'PENDING'（送信待ち）、'SUCCESS'（送信成功）、'FAILED'（送信失敗） |
