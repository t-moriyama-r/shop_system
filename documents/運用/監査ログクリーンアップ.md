# 期限切れ監査ログのクリーンアップ

`audit_logs` テーブルはシステム操作（ログイン成否・アカウント操作等）の証跡を記録し続けるため、放置するとテーブルが肥大化する。保持期間（1ヶ月）を超過したレコードを日次バッチで物理削除する（BP-006 / BP-012、NFR-009）。

改ざん防止のため `audit_logs` へはアプリケーション層から INSERT のみを許可し、UPDATE・DELETE は不可とする方針だが、**保持期間超過レコードの削除はこのクリーンアップバッチのみ例外的に許可する**。

## コマンド

```sh
pnpm db:cleanup-audit-logs
```

実行時刻から 1 ヶ月前（`AUDIT_LOG_RETENTION_MONTHS = 1`）をカットオフとし、`created_at < cutoff` の監査ログを削除して削除件数を標準出力に表示する（`DB/cleanup-audit-logs.ts` → `deleteExpiredAuditLogs(auditLogRetentionCutoff())`）。

保持期間を変更する場合は `DB/audit-logs.ts` の `AUDIT_LOG_RETENTION_MONTHS` を修正する。

## 定期実行

本番運用では cron 等で日次実行する（例: 毎日深夜 3:00）。

```sh
0 3 * * * cd /path/to/shop_system && pnpm db:cleanup-audit-logs >> /var/log/shop_system/audit-log-cleanup.log 2>&1
```
