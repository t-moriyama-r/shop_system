# 期限切れセッションのクリーンアップ

`sessions` テーブルは認証時に期限切れレコードを認証対象から除外するのみで(`Backend/middleware/auth.ts`)、レコード自体は削除されない(ログアウト時のみ明示的に削除)。放置するとテーブルが肥大化するため、期限切れセッションを定期的に削除する。

## コマンド

```sh
pnpm db:cleanup-sessions
```

`expires_at < now()` のセッションを削除し、削除件数を標準出力に表示する(`DB/cleanup-sessions.ts` → `deleteExpiredSessions()`)。

## 定期実行

本番運用では cron 等で定期実行する(例: 15 分ごと)。

```sh
*/15 * * * * cd /path/to/shop_system && pnpm db:cleanup-sessions >> /var/log/shop_system/session-cleanup.log 2>&1
```
